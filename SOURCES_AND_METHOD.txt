2) METHOD: BORROW FIRST, BUILD SECOND
----------------------------------------------------------------
Rule we settled on (saves tokens / time):

  A. Search for open / recovered hubs for this place ID.
  B. Prefer READABLE sources (Boblo opensource_egg). Copy the
     movement + remote pattern into our thin panel/core.
  C. If only obfuscated hubs exist (Potato, Axur, Luraph, WeAreDevs):
     do NOT reverse by hand. Run SAE_DumpHub.lua first, then the hub,
     then read dumped HttpGet / loadstring files + remotes.log.
  D. Our panel/GUI stays ours (gethui + protect). Core movement
     should match a known-working hub, not invent AlignPosition/fly.
